# Log Cabin Scout brand kit

| Asset | Use |
| --- | --- |
| `../logo-mark.svg` | Editable cabin master and website emblem |
| `horizontal-logo.svg` | Horizontal lockup for documents and headers |
| `profile-icon.svg` | Square avatar source, with room for Instagram's circular crop |
| `profile-icon.png` | 1080 × 1080 Instagram upload |
| `../favicon.svg` | Tight crop for browser tabs |
| `social-preview.svg` | Editable 1200 × 630 link preview |
| `../social-card.png` | Raster link preview for social platforms |
| `instagram-profile-a.png` | Original concept reference |

The SVGs contain named vector shapes. The standalone lockup and preview use
outlined lettering for consistent display across apps. The editable cabin artwork
uses pine, parchment and rust, with goldenrod reserved for the preview accent.
See the [brand guide](../../docs/brand-guide.md) for typography and usage.
