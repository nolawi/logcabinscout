# Log Cabin Scout

A React + TypeScript + Vite starter for discovering log cabins for sale.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The homepage currently contains clearly marked **illustrative sample listings**, not real estate data. The listing ingestion and database integration are future steps.

For GitHub Pages, the Vite base path is set to `/logcabinscout/`. Change this to `/` when moving to a custom domain.
